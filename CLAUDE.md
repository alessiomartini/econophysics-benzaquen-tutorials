# Claude Code instructions

## Project

Lecture notes and Jupyter tutorials for econophysics.

## Workflow

- Read `README.md` and the relevant notebook before editing.
- Preserve notebook outputs and scientific context unless regeneration is requested.
- Run affected notebooks from a clean, reproducible environment when practical,
  and check for execution errors and meaningful output.
- Do not fabricate data, results, citations, or plots.
- Keep checkpoints, caches, and environment files out of git; inspect the diff
  before committing.
